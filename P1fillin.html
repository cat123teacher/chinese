語音設定教學指南

如果您點擊 🔊 發音按鈕後沒有聲音，或者廣東話聽起來像普通話，請跟著以下簡單的系統步驟進行設定：

蘋果手機 (iPhone / iPad) 設定：

  1. 打開手機的 **「設定」 (Settings)**。
  2. 點擊 **「輔助使用」 (Accessibility)**。
  3. 選擇 **「朗讀內容」 (Spoken Content)**。
  4. 點擊 **「聲音」 (Voices)**。
  5. 選擇 **「中文」 (Chinese)** ➔ 點擊 **「廣東話（香港）」** 或 **「中文（普通話）」**。
  6. 下載並選擇高品質的語音（例如首選 Sin-ji（仙兒） 或者是 Ting-ting（婷婷））。
  7. 確保 **「朗讀選取範圍」 (Speak Selection)** 已經開啟。

安卓手機 (Android) 設定：

  1. 打開手機的 **「設定」 (Settings)**。
  2. 搜尋 **「文字轉語音」 (Text-to-Speech / TTS)** 或點擊 **「系統設定」 ➔ 「無障礙」 ➔ 「文字轉語音輸出」**。
  3. 選擇 **「慣用引擎」** 為 **「Google 文字轉語音引擎」**。
  4. 點擊引擎旁的 **「設定 (齒輪)」** ➔ **「安裝語音資料」**。
  5. 找到並下載 **「粵語（香港）」** 或 **「中文（中國）」** 的語音包。
  6. 返回並將「語言」設定為相應的「廣東話」或「普通話」即可。
