📱 聽不到廣東話或普通話？

如果你的手機或平板無法朗讀語音，通常是因為系統尚未下載廣東話或普通話的語音包。請跟隨以下步驟輕鬆開啟設定：

🍎 iPhone / iPad (iOS) 設定方法：
  1. 開啟 iPhone 「設定」 (Settings)
  2. 進入 「輔助功能」 (Accessibility) ➔ 點選 「朗讀內容」 (Spoken Content)
  3. 點選 「聲音」 (Voices)
  4. 選擇 「中文」，然後下載並勾選 「廣東話 (香港)」 或 「普通話 (中國大陸/台灣)」
  5. 建議選擇「增強版」音質，發音會更自然清晰！
🤖 Android (三星 / Xiaomi / Pixel 等) 設定方法：
  1. 開啟手機 「設定」 (Settings)
  2. 點選 「系統 / 一般管理」 ➔ 「語言與輸入法」
  3. 點選 「文字轉語音輸出」 (Text-to-speech output)
  4. 點選 Preferred Engine 旁的 ⚙️ 齒輪圖示 ➔ 「安裝語音資料」
  5. 找到並下載 「廣東話 (香港)」 或 「中文 (普通話)」 語音包。
